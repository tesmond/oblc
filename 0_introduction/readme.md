# One Billion Row Challenge

The one billion row challenge was originally constructed as a challenge for Java programmers to pass a 1 billion line simple CSV file the CSV file consists of a city name a semi-colon and then a floating point temperature value. The goal is to parse the file and collect the minimum, maximum and average temperature for each of the cities and then return the results in order to the console. 

The 1 million row file will have up to 10,000 Unique city names in UTF-8 format. The temperatures will be from -99.9 to 99.9 always one decimal place. Each row will have a new line character. 

I decided to do the challenge in Python and go in order to see how fast Python could be compared to other languages.
